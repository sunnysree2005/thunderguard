# ThunderGuard ⚡

**ThunderGuard** is an early lightning detection and multi-channel alert system designed to protect rural communities and outdoor workers from sudden lightning strikes, especially when standard internet infrastructure fails.

---

## 🚀 Features
* **Real-Time Detection:** Fetches live weather and lightning risk data to monitor hazardous conditions.
* **Smart Alerting:** Triggers immediate warnings when lightning density exceeds safety thresholds.
* **Resilient Communication:** Built to support multi-channel notifications (App push & SMS gateway simulation) for low-bandwidth or offline scenarios.
* **Lightweight UI:** Simple and intuitive interface for users to check local safety status.

---

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **Frontend / Mobile App:** Flutter (Cross-platform)
* **APIs:** OpenWeatherMap / Weather Data Feeds
